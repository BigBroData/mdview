# Темы mdview

Тема — это обычный CSS-файл. Он переопределяет переменные (токены) в начале
`src/client/styles/app.css`; ничего больше менять не нужно. Такой файл легко написать руками
или поручить агенту.

## Где лежат

- Свои темы: `~/.config/mdview/themes/<имя>.css` (или `$XDG_CONFIG_HOME/mdview/themes`). Имя файла без `.css` —
  имя темы в списке. Папки может не быть: создайте её, когда понадобится.
- Встроенные: `sepia`, `dusk`, `contrast` (их исходники — `src/client/themes-builtin.ts`). Свой файл с тем же именем
  заменяет встроенную тему.
- Ограничения: файл до 256 КиБ, до 50 файлов, имена не начинаются с точки.

## Как переключать

**Ctrl+Shift+T** открывает список. ↑/↓ сразу показывают тему, Enter оставляет, Esc возвращает прежнюю,
щелчок по пункту выбирает. «System» — собственные цвета приложения, светлые или тёмные по настройке системы.
Выбор запоминается между запусками.

Файлы перечитываются при открытии списка и когда окно снова получает фокус: сохранили тему в редакторе,
вернулись в mdview — изменения уже видны. Тема, выбранная ранее и потом удалённая, просто не применяется.

## Что можно менять

Все цвета заданы переменными на `:root`. Тема должна задать **полный набор**: тогда системная светлая/тёмная
настройка не просачивается в неё.

| Переменная | Что красит |
| --- | --- |
| `--bg` | фон страницы |
| `--fg` | основной текст |
| `--fg-muted` | второстепенный текст: подписи, цитаты, подсказки |
| `--accent` | ссылки, активная вкладка, текущее совпадение поиска, выбранный пункт списка |
| `--accent-soft` | мягкая подсветка под акцентом (наведение, ручка ленты) |
| `--on-accent` | текст на фоне `--accent` |
| `--rule`, `--rule-strong` | тонкие линии (под заголовками, таблицы) и заметные рамки (панели) |
| `--surface`, `--surface-ink` | фон и текст блоков кода, панелей, полосы вкладок |
| `--mark` | подсветка совпадений поиска |
| `--selection` | выделение мышью |
| `--tok-comment`, `--tok-keyword`, `--tok-string`, `--tok-number`, `--tok-title`, `--tok-type`, `--tok-attr`, `--tok-variable`, `--tok-meta` | цвета подсветки кода |

Кроме цветов можно задать `--font-text`, `--font-mono` (только установленные в системе шрифты: внешние адреса
для шрифтов и `@import` запрещены политикой безопасности окна), `--text-leading` (межстрочный интервал), `--measure`
(ширина колонки, по умолчанию `44rem`) и `--gutter`. **Не задавайте** `--text-size`: это выбор читателя (Ctrl+плюс/минус).

Чтобы стрелки прокрутки и поля ввода окрасились под тему, добавьте `color-scheme: light` или `dark`.

Допустим и любой другой CSS (`.document h1 { … }`), но переменных обычно хватает. Корневому элементу при активной теме
выставлен атрибут `data-theme="<имя>"`, по нему можно написать правило только для неё.

## Пример

```css
/* ~/.config/mdview/themes/forest.css */
:root {
  color-scheme: dark;
  --bg: #1b2420;
  --fg: #dfe8e1;
  --fg-muted: #8fa396;
  --accent: #7fd1a0;
  --accent-soft: rgba(127, 209, 160, 0.16);
  --on-accent: #10201a;
  --rule: #2b3830;
  --rule-strong: #3f5247;
  --surface: #232e28;
  --surface-ink: #dfe8e1;
  --mark: #5b5a1f;
  --selection: rgba(127, 209, 160, 0.28);
  --tok-comment: #7a9084;
  --tok-keyword: #c3a0e0;
  --tok-string: #a6d189;
  --tok-number: #e0a46a;
  --tok-title: #7fd1a0;
  --tok-type: #e5c97c;
  --tok-attr: #e0a46a;
  --tok-variable: #e27d7d;
  --tok-meta: #9bb0a3;
}
```

## Тема, которая следует за системой

Обычный файл действует всегда. Чтобы тема сама переключалась между светлой и тёмной, добавьте в неё блок
`@media (prefers-color-scheme: dark) { :root { … } }` с тёмными значениями, а светлые оставьте в `:root`.

## Подсказка для агента

> Напиши тему для mdview: CSS-файл `~/.config/mdview/themes/<имя>.css`, который задаёт все переменные из `docs/themes.md`
> (`--bg`, `--fg`, … `--tok-meta`) и `color-scheme`. Проверь контраст `--fg` на `--bg` (не ниже 4.5:1), `--on-accent`
> на `--accent` и `--fg-muted` на `--bg` (не ниже 3:1). Сохрани файл и открой mdview: тема появится в списке Ctrl+Shift+T.

## Что не сделано

Переключение темы по часам, тема на документ, предпросмотр сразу нескольких тем рядом.
