# Backlog

Срезано из первой версии осознанно. Порядок примерный.

## Этап 2 — настольное приложение (собрано и проверено на Pop!_OS 22.04)
- Осталось проверить руками: `sudo apt install ./mdview_0.1.0_amd64.deb`, двойной клик по .md (при необходимости `xdg-mime default mdview.desktop text/markdown`), перетаскивание, сеанс Wayland.
- Единственный экземпляр: сейчас каждый открытый файл — отдельное окно (так и задумано), но при желании можно переиспользовать окно.
- Запоминать размер окна между запусками.

## Рендер
- Пользовательские темы: файл `~/.config/mdview/themes/<имя>.css`, переопределяющий переменные `:root`; переключатель темы.
- Ограниченный сырой HTML через санитайзер (details/summary, `<img width>`), как у GitHub.
- Mermaid: ленивая подгрузка только при наличии блока ` ```mermaid `.
- Панель оглавления сбоку как опция к ленте заголовков; якоря у заголовков; ссылки на соседние `.md` открываются в просмотрщике.
- Сноски (`[^1]`), подсветка `==текст==`, emoji-шорткоды — по запросу.
- Набор языков подсветки: сейчас `lib/common` (~37 языков, ~ половина бандла); при необходимости — явный список.

## Качество
- Инкрементальная перерисовка (только изменившиеся блоки) — если на больших файлах будет заметно мигание.
- Локализация интерфейса (сейчас три служебных сообщения на английском).
- Печать/экспорт в PDF через диалог печати.

## Этап 3 — редактор
